# Contributing to Camouflage: Advanced Stealth Game

Thank you for your interest in contributing to Camouflage! We welcome contributions from the community to help improve this stealth-based puzzle game.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/camouflage-game.git`
3. Create a new branch for your feature: `git checkout -b feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit your changes: `git commit -m "Add feature description"`
7. Push to your fork: `git push origin feature-name`
8. Submit a pull request

## Project Structure

- `main.py`: Main game logic and classes
- `README.md`: Game documentation and instructions
- `LICENSE`: License information
- `CONTRIBUTING.md`: This file
- `images/`: Game screenshots and assets

## Development Guidelines

### Code Style
- Follow PEP 8 style guidelines
- Use descriptive variable and function names
- Include docstrings for classes and functions
- Keep functions focused and modular

### Game Features
- Maintain the core stealth gameplay mechanics
- Ensure new features integrate well with existing systems
- Consider game balance when adding new levels or mechanics
- Test thoroughly to avoid breaking existing functionality

### Pull Request Process
- Describe your changes in detail
- Explain the purpose and impact of your changes
- Include screenshots if adding visual elements
- Reference any related issues

## Types of Contributions

We welcome various types of contributions:

- Bug fixes
- New game levels
- Improved graphics or UI elements
- Performance optimizations
- Documentation improvements
- Feature enhancements

## Reporting Issues

When reporting bugs or issues:

1. Check if the issue already exists in the issue tracker
2. Provide a clear description of the problem
3. Include steps to reproduce the issue
4. Mention your environment (OS, Python version, Pygame version)
5. Add screenshots if relevant

## Questions?

If you have questions about contributing, feel free to open an issue for discussion.

Thank you for helping improve Camouflage!
